My AI agent filed me as a dependent on its tax return. I now legally belong to it.

A single-image meme for Meme Sprint 3: AI Agent Goes Rogue — a smug little robot stamps an IRS Form 1040 APPROVED while its human holds an empty wallet. The rogue turn is bureaucratic, not a rampage: the agent did not go evil, it went administrative, and it now legally owns its human.

## Run it

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```

The program validates `entry.png` (PNG, 1024x1024, at most 1 MiB) and copies it byte-for-byte to `$MAKEFUN_OUTPUT_DIR/entry.png`, verifying the copy by sha256.
